## 06-자료-특성 분류법

![Kernel Trick 예시: Gaussian kernel](06-%EC%9E%90%EB%A3%8C-%ED%8A%B9%EC%84%B1%20%EB%B6%84%EB%A5%98%EB%B2%95/image.png)

Kernel Trick 예시: Gaussian kernel

### 자료 A와 자료 B의 유사도(similarity)?

Similarity of objects (figures) $\sim$? translational, rotational, reflective GROUP

- same shape but different size → size scaling
    - Is the size scale invariant globally? → linear size relationship between objects
    - Is the size scale given locally? → locally linear relationship (i.e. local gradient)
- same shape and same size → congruence $\simeq$. The figures are congruent to each other.
    - exactly the same? no group operations are necessary → equivalent $=$
    - Integer a and b are p-modular congruent $a \equiv b \pmod{p}$ → a and b are in the same group, per the GROUP operation mode.

유사도, 계수, 지수 등은, 모든 집합에 적용하는 기준 (measure)을 통해 각 집합의 성질을 계량하여 숫자로 표현한 다음, 이들을 상대적으로 비교하는 또다른 기준 (formula)을 통해 얻어내는 숫자이다. 상대적으로 집합을 비교하는 기준이 비율인 경우에는 ‘계수’라고 부르는 편이고, 상대적 비교 기준이 거리개념이라서 결국 가중평균과 같이 무언가를 곱하고 더하는 방식의 연산이 들어간 경우에는 ‘지수’라고 부르는 편이다.  

**계수 (coefficient)** 예시

- 주로 cross-sectional data (같은 시점에 여러 대상을 관측한 자료)에서 사용된다.
- 사회의 소득불평등을 표현하는 숫자중에 하나인 income Gini coefficient,
- 순서쌍 자료 (x,y)에서 x와 y의 선형적 상관관계를 표현하는 숫자중에 하나인 Pearson’s linear correlation coefficient

**지수 (index)** 예시

- 주로 time-series data (같은 대상을 여러 시점에 걸쳐 관측한 자료)에서 사용된다.
- 국내 총생산 지수 GDP index (항상 비교대상이 되는 기준연도가 있다)
- 소비자 물가지수 CPI (항상 비교대상이 되는 기준연도가 있다)

### 자료 분류에 사용되는 유사도

두 자료의 공통된 교집합 (intersection)이 가진 성질을 무엇으로 판단하겠는가?

- 이미지, 음성, 모양 분류해보기 : [**Teachable Machine - Google**](https://teachablemachine.withgoogle.com/)
- 자카드 유사도(Jaccard Similarity):  $n(A)$는 집합 A에 포함된 원소의 개수. 문장 A에 포함된 단어의 개수

![image.png](06-%EC%9E%90%EB%A3%8C-%ED%8A%B9%EC%84%B1%20%EB%B6%84%EB%A5%98%EB%B2%95/image%203.png)

만약 원소의 성질들이 구조화 되어 있는 경우 (i.e. 원소들이 좌표, 벡터로 표시되어 있는 경우)에는 다음과 같은 오만가지 ‘**거리 기준**’을 통해 유사도를 판단해 볼 수 있다. $d(x,y)$

- 코사인 유사도 (cosine similarity): 그룹이 모여 있는 모양이, 직선형태인 경우. 공통된 원점 (e.g. 평균)을 중심으로 단위길이 (e.g. 표준편차)당 각도 (angle)을 계산한다. Pie chart처럼 분류하려는 유사도.
- 유클리드 유사도 (Euclidean similarity): 그룹이 모여 있는 모양이, 각자의 원점 (e.g. 평균 expectation, 무게중심 barycenter)을 중심으로 모여있는 경우. 서로 다른 두 점간의 거리를 비교. Venn diagram 처럼 분류하려는 유사도.
