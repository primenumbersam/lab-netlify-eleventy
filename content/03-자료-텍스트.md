### 기능별 출력

인공지능 모형에 입력되는 자료값이 텍스트 (Text)인 경우, 인공지능 모형은 다음과 같은 기능을 수행하여 결과값을 출력한다.

- 요약: 주제어 (중요한 단어)들을 찾고, 이들을 순서에 맞게 연결한 문장 (수열)
- 번역: 사전의 단어들과 수많은 관용문들을 학습한 후, 이들과 유사도가 가장 높은 번역문장을 출력
- 분류와 비교: 기존 텍스트 자료들이 속한 그룹과의 유사도를 계산

### 비정형자료 (raw data) vs. 정형자료 (structured data)

자료 구조화 (데이터 전처리): 날 것 자료에서 ‘불필요한 부분’을 걸러내고, 주제에 적절한 구성성분 (field)를 바탕으로 자료를 정리하는 과정  

![image.png](03-%EC%9E%90%EB%A3%8C-%ED%85%8D%EC%8A%A4%ED%8A%B8/image%201.png)

- 연속형 자료 (양적 자료): 측정으로 수치화된 성질에 ‘표준 단위’ (모두가 약속으로 정한 단위)가 있어 자료값을 기반으로 구간 (interval)을 부여할 수 있는 경우.
- 범주형 자료 (질적 자료): 측정으로 수치화하려는 성질에 객관적 단위가 없기 때문에 주관적으로 숫자값을 부여할 수 있으며, 구조화된 자료값이 일반적으로 빈도수 (frequency)가 되는 경우

 

### 2개 문장으로 구성된 글에서, 주요단어들 (keywords) 찾기

1. 글(context)은, 문장 A와 B라는 집합 (sentences)의 합집합 $A \cup B$이다. 문장 (집합) A, B는 레코드 record라고 부르며, 문장 (집합)들의 개수 (A, B 2개)는 레코드의 개수이다. 통계에서는 관측수 number of observations이다.
2. 각 문장을 서로 다른 단어 (토큰 token) 단위로 끊고, 각 단어들을 객관적 순서없이 (주관적 순서대로) 나열하여 각 단어들에 숫자를 부여. 데이터 필드 (field)의 차원, 배열 (array)의 차원, 벡터 (vector)의 차원(dimension)을 설정하는 단계. one-hot vector (state vector, basis, 하나의 성분만 1이고, 나머지 모든 성분은 0인 벡터)
3. 각 필드, 배열의 칸, 벡터의 성분에 해당하는 단어의 빈도수 (숫자)를 계산하여 넣는다

![image.png](03-%EC%9E%90%EB%A3%8C-%ED%85%8D%EC%8A%A4%ED%8A%B8/image%202.png)

두 문장의 단어들을 비료해 보면, ‘마스크, 착용’ 이라는 단어들이 가장 많이 등장했다. 

집합은 단어들로 구성되어 있고 각 문장 A와 B는 서로 다른 집합이라고 생각하면, ‘마스크, 착용’이라는 단어들은 두 집합의 교집합 $A \cap B$에 속하는 원소 (element, factor)이다.

### 새로운 단어의 의미를 유추해 보기

![비슷한 단어들로 묶어주기 (grouping). 구조를 부여해서 부분 군으로 묶거나 대응하기](03-%EC%9E%90%EB%A3%8C-%ED%85%8D%EC%8A%A4%ED%8A%B8/image%205.png)

비슷한 단어들로 묶어주기 (grouping). 구조를 부여해서 부분 군으로 묶거나 대응하기

단어 임페딩 벡터 (word embedding vector)는 각 단어들을 분류의 기준, 부분군 (subgroup)의 기준에 맞게 분류한 다음 각 기준에서의 좌표를 나타낸 벡터이다. 당연히 벡터의 성분별 기준이 무엇이 되어야할 것인가가 가장 중요하다. 

‘컴퓨터’라는 새로운 단어의 의미를 몰라서 유추해야 한다. 그런데 그동안 2가지 기준으로 A = {연필, 종이, 손편지}라는 벡터 부분군과 B = {인공지능, 프린터, 스마트폰}라는 벡터 부분군 (그룹)을 분류해 놓았다고 가정하자. 분류해 놓은 기준은 순서를 부여할 수 있는 2가지 였다. 하나 (x축) 는 출시연도, 다른 하나 (y축)는 검색어빈도수 였다.

A = { 연필 = $a_1$= (1, 2), 종이 = $a_2$=(2, 1), 손편지 = $a_3$=(2, 2) }

B = { 인공지능로봇 = $b_1$= (5, 10), 프린터 = $b_2$= (6, 5), 스마트폰 = $b_3$ = (7, 9) }

그룹분류에 사용된 기준을 이용해 ‘컴퓨터’라는 단어에도 좌표를 부여하였다 (i.e. 단어를 단어 임베딩 벡터로 표현하였다). 컴퓨터 = $x$ = (4, 6)

‘컴퓨터’라는 단어가 가진 의미는 A 그룹과 B 그룹이 가진 의미 중 어디에 더 가까울까? ‘컴퓨터’ 단어 임베딩 벡터 (좌표)는 A 그룹의 대표적 좌표와 B 그룹의 대표적 좌표 중에 어디에 더 가까울까? 

각 그룹의 대푯값 = 각 문장을 대표하는 임베딩 벡터는, 각 문장에 포함된 단어들을 표현한 벡터의 각 성분별 ‘평균 (average)’를 사용한다고 가정해보자.

A의 대표 벡터 좌표 = a = $(\frac{1+2+2}{3}, \frac{2+1+2}{3})=(5/3,5/3)$

B의 대표 벡터 좌표 = b = $(\frac{5+6+7}{3}, \frac{10+5+9}{3})=(6,8)$

또한 서로 다른 벡터 (공간 상의 좌표, 점)간의 ‘거리’는 Euclidean distance를 사용한다고 가정해보자.   

$||x-y|| :=[(x-y) \cdot (x-y) ]^{1/2}=\sqrt{(x_1-y_1)^2+(x_2-y_2)^2 }$

컴퓨터 = $x$ = (4, 6)으로 측정되었기에,

점 x와 A의 대표점 사이의 거리 $||x-a||$ = $\sqrt{(4-1.67)^2+(6-1.67)^2}\approx 4.92$

점 x와 B의 대표점 사이의 거리 $||x-b||$ = $\sqrt{(4-6)^2+(6-8)^2} \approx 2.83$

따라서, 위에서 사용한 

- 대표값을 정하는 기준,
- 좌표간 거리를 비교하는 기준,
- 좌표를 부여한 기준이 모두 ‘정확할 것이다’라는 가정하에,

‘컴퓨터’라는 단어의 의미는 문장 B에 들어있는 단어들의 의미와 유사할 것이라고 추론해 볼 수 있다.
